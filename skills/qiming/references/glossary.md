# 术语，一句话说清楚

| 名词 | 人话与例子 |
| --- | --- |
| 会员 / member | 用户创建或接管、要长期维护的对象；例如一个本地 AI 服务，不是付费订阅 |
| 子会员 | 自己也有入口、用途和维护责任的下属对象；例如该服务的调用 Skill |
| 权威记录 | 同一事实只维护一处的原件；搜索索引不算原件 |
| 清单 / manifest | 记录这个项目是谁、去哪里读资料的 workspace.json |
| 映射 / profile | 告诉启明“我的任务在什么目录、标题用哪个字段” |
| 安装包 / 种子 | 首次接入和升级用的 qiming；不代替项目自己的规则 |
| 项目实例 | `.qiming/qiming-user`，可以独立演化、随项目搬走 |
| 宿主 / host | 执行 Skill 的应用，例如 Claude Code；模型是应用调用的 AI |
| 短入口 | START.md，下一次会话先看它知道做到哪了 |
| 启动摘要 | startup.md，少量一直影响决策的规则，刷新后写入 AGENTS.md |
| 指纹 | 文件字节的 SHA-256；别人改了文件就不能按旧内容覆盖 |
| 受控写入 | plan 检查影响，再 apply 保存与记录；失败用 reconcile 检查恢复 |
| 附属成果 | 归已有会员管理的文件，不必每个文件都建立会员 |
| 凭据引用 | 密码库的 provider 与不含秘密的定位 ID，绝不是密码本身 |
| 验证 | 实际执行并留证据；文件存在或命令返回成功不代表业务能用 |

例如：“给本地 AI 入会”是建立该服务档案，记录入口、维护责任和已验证状态；调用一次第三方 AI 则通常只是外部依赖，不需要登记为会员。
